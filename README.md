# Dictol

基于 Electron、React、TypeScript、Tailwind CSS 和 shadcn/ui 的桌面词典应用。

## 开发环境

- Node.js 22.12 或更高版本；仓库的 `.nvmrc` 固定为 22.15.1。
- npm 10 或更高版本。

## 常用命令

```bash
nvm use
npm install
npm run dev
```

```bash
npm run typecheck
npm run lint
npm run build
```

架构和词典兼容性分析见 [`EXECUTION_PLAN.md`](./EXECUTION_PLAN.md)。
